# The Straddie Twins

A public companion site that explains the two digital twins of Minjerribah (North Stradbroke Island, Quandamooka Country) part by part, for anyone arriving cold: what each twin is, what is real, modelled, proposed or not known, every system, layer, board, pack and instrument, and how to open either one.

The twins themselves live in their own repositories and this site never changes them:

- First build: https://github.com/auraofintelligence/minjerribah-living-twin (live at https://auraofintelligence.github.io/minjerribah-living-twin/)
- Second build: https://github.com/auraofintelligence/second-island (live at https://auraofintelligence.github.io/second-island/)

Plain HTML, CSS and JavaScript. No build step, no framework, no tracking, no network calls beyond the Google Fonts stylesheet. The list of parts is `assets/components.js`; the counts on every page are computed from it.
