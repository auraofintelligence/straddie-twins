Open them yourself

Both twins run in a browser. Neither needs an account.

Each build is a public page you can open now, and a folder you can run on your own computer with one command. Nothing installs, nothing signs you in, and once a page has loaded, nothing reaches the network.

Opening the first build

A dark morning, a strip that offers the light, and a keyboard.

The first thing on screen is the acknowledgement of Country, then four arrival screens ending at three doors: two onto the island, one into How it works. The simulated clock opens at 5:20am against a 5:39am sunrise, so the island behind the doors is sky and silhouette. A strip says the sun is five degrees under the horizon, says when sunrise is, and offers to move the clock to twenty minutes after it, the first moment there is light on the ground. Take it. For the next hour the strip keeps a quieter line up, because a low sun leaves most of the ground in its own shadow.

The build is made for a laptop with a keyboard: every board has a key, and the camera has five modes on Tab. The keys that matter in the first five minutes are in the table. The full list, one table per area, is the build's own keyboard file, and the arrival screens show the same map.

What to expect of the picture: the README, measured on 9 August 2026, says the simulation step runs at 6.23 milliseconds against a budget of 4, so a slower laptop will feel it; the drawing itself is comfortable. Close range in a township is hazed, and the bay water renders green. Those are the build's own words about itself.

Opening the second build

Two pages of numbers, each one pointing at its record.

The front page asks one question, can I get off the island and can my car, and answers it in eight panels from the printed boat and bus timetables read against the island clock. Every value carries a small tag, KNOWN or MODELLED, and where the page has nothing to stand on it prints "contested or unknown" with the date it last looked. There is nothing to click and nothing to fly; it is a page to read. The ferry page is explained panel by panel on this site.

A line at the foot leads to the lab: a calibration target, the island clock, the sun and tide panels, and the controls that step time. The lab is the bench the checking tools point at, and it looks like one.

Two pages

index.html and lab.html

The ferry page is the page for a person. The lab is the page for the instruments, and the second build's own state of play says the two were split on 20 August 2026 after the front page was found carrying a calibration checkerboard and paragraphs of the build explaining its own discipline to itself.

On your own machine

One program to install, one command to run.

Both builds need Node, the program that runs JavaScript outside a browser. Neither has a build step, a package to install or a network call at run time; the first build carries its game engine inside the repository, and the second carries a small kernel of its own. Clone a repository, run its server, open the address.

First build

Port 4271

git clone https://github.com/auraofintelligence/minjerribah-living-twin.git
cd minjerribah-living-twin
node tools/serve.js

Then open http://localhost:4271/. With no browser at all, the same island runs in the terminal:

node tools/headless.mjs --ticks 4320 --profile
node tools/headless.mjs --ticks 52560 --profile
node tools/headless.mjs --determinism

The first is thirty simulated days with timings, the second a simulated year, which the README says takes about five minutes, and the third runs the world twice and compares the two. On the running page, TWIN.probe() in the browser console prints the whole state and TWIN.errors() anything that went wrong.

Second build

Port 4281

git clone https://github.com/auraofintelligence/second-island.git
cd second-island
node tools/serve.mjs

Then open http://localhost:4281/ for the ferry page and http://localhost:4281/lab.html for the bench. The instruments run from the same folder:

node tools/gate.mjs
node tools/headless.mjs
node tools/determinism.mjs
node tools/selftest.mjs
node tools/board.mjs read

The gate checks every file against the build's rules; headless runs a simulated year in a fraction of a second; determinism runs it twice and names any drift; the self-test breaks a copy of the build 33 ways and checks each break is caught; the board prints the noticeboard.

The two ports are not interchangeable. The second build's gate fails the build if either of the first build's port numbers appears in its files, which is one of the ways the two repositories are kept apart.
