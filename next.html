First build

Designed but not written yet

  • Five modules named at start-up, none written. Fire: danger, ignition, spread, track closures. Coast: erosion and build-up at Amity Point. Groundwater: aquifer, lakes, borefield. Then a whole-day board, and a nature board.
  • Scanned objects. The rules are written down to the file names. The folder is empty.
  • Ten ways in, lowest tech first: a spoken correction, paper cards, a tape measure, business and community facts, scans, sightings, wishes, scenario ideas, memory anchors, event plans. Only the spoken correction has been used.
  • The era lane would show the island as it was. No old maps pinned to real coordinates, no old aerial photos.
  • Scenario runs. Only the stamp exists, the record that a run happened. Nothing has been stamped.
  • The gate was red at the last save, with twelve findings. Mostly council records with no source, plus files whose fingerprints no longer match. New records and scenario stamps stay blocked.
  • A scheduled sync. Every data link says how often to run it. Nothing runs on a timer. The weather goes stale and the screen reads “not known”.

Second build

Not on screen yet

  • No map, no island shape. The renderer draws one test scene of flat rectangles, checkable pixel by pixel. A coastline waits on the licence call, because that data comes with a share-alike rule.
  • No residents. The rule says a made-up person gets labelled on their card. Nobody exists yet.
  • No live feed. The ferry page reads the printed timetable against the clock. On the day the barge stops, the page still shows it sailing. The build calls that its worst gap.
  • Live buses. TransLink positions over the printed timetable. Not started.
  • The biggest unknown is two numbers: sailings a day, and vehicles per barge. The operators have them. No open source lists them.
  • The tide table for Dunwich port, not obtained. The tide model has no numbers, so the page shows a marker and a date.
  • Four packs in the inbox: OpenStreetMap, weather, census, ecology. Fetched with receipts, waiting on the licence call.

Putting something in

What a person can put in today

A resident told the first build a business had closed. The record closed, with the correction and the date on it. Typed-up facts go through the intake tool, which needs consent and blurs the location. Your entry becomes the same kind of record as a council document, checked the same way, with your name on it. No points, no badges, no tallies.

The owner typed up the boat timetables on 19 August 2026. The second build counts that as a source. The file names who said it and when, and it is sealed, so a later change gets caught.

Neither build

No form, no portal, no account

Somebody types the facts in by hand. Both builds write files for a person to send on. Neither posts anything by itself, by choice.
